# Solo GAME

## Objetivo
Solo GAME es una página web sencilla para mostrar videojuegos nuevos, destacados y próximos lanzamientos.

## Tecnologías
- HTML5
- CSS3
- Bootstrap 5
- jQuery

## Funcionalidades
- Navegación por secciones.
- Menú lateral.
- Carrusel de recomendaciones.
- Búsqueda por nombre o género.
- Animación de tarjetas con jQuery.
- Diseño adaptable a computador, tablet y celular.
- Iconos de validación HTML5 y CSS3 en el footer.

## Estructura
- `index.html`: página principal.
- `css/estilos.css`: estilos y diseño.
- `js/main.js`: interacción y animaciones.
- `img/`: imágenes del proyecto.

## Ejecución
1. Descargar o descomprimir la carpeta.
2. Abrir `index.html` en un navegador.
3. Para Bootstrap y jQuery se necesita conexión a Internet porque se cargan desde CDN.

## Accesibilidad y buenas prácticas
Se usan etiquetas semánticas, textos alternativos en imágenes, etiquetas para formularios, foco visible, navegación clara y clases CSS con metodología BEM.
